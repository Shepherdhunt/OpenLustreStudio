Import existing Lustre — paste it below or choose a .lus file. Its node / function declarations (plus any type / const) are added to this project for reuse. The dataflow subset OpenLustre emits round-trips; unsupported constructs (assertions, inline contracts) report a located error.

A state machine belongs to one operator and is its body: it reads that operator's inputs and drives its outputs. Author it as text — states, transitions, and the variables each state drives — and it lowers to dataflow automatically. Every output must be assigned in every state (SCADE strictness), or the build reports it. Hierarchy: a state can refine another machine (e.g. Active: refine Spin) — that machine runs nested while the state is active, restarting on entry. Or nest a region inline with a { … } block: Active: drive=1 { initial Lo; history; Lo: level=0; Hi: level=1; Lo -> Hi when up; Hi -> Lo when down }. The sub-automaton runs while the state is active; add history to resume the held sub-state on re-entry instead of restarting. Signals: declare broadcast signals in the signals field — pulse is a pure (presence-only) signal, level: int32 a valued one. A state emits one with emit pulse or emit level = 2 (optionally … when cond); anywhere else — including a parallel region — test presence with pulse? and read a valued signal with level. A signal is present the same cycle it is emitted, so it is how two parallel automata talk.
